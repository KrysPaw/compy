Main idea:
- Web app for comparing things e.g. phones, electronics, job offers, holiday hotels
- User is able to create a comparison
- Comparison is a group of things
- User define criteria to describe things e.g. price, amount of something, distance
- User add entries by providing criteria values
- The app saves the entries and show them to the user
- User can compare things by sorting by criteria

Tech stack (must have):
- NextJs
- NestJs
- Prisma
- Playwright
- Tailwind
